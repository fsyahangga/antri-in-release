# antri.in — unduhan APK Android

Aplikasi antrean fisik komunitas driver di titik jemput mal (2 lobby + 7 tandon + waiting list).
**Proof of concept** — aplikasi komunitas independen, bukan produk resmi Green SM maupun Pakuwon Group.

Repo ini hanya berisi rilis APK; kode sumber tidak dipublikasikan di sini.
Versi web (tanpa instal): https://antri-in.web.app

## Pasang di HP Android

1. Buka halaman [Releases](../../releases/latest) dari HP, unduh `antri-in.apk`.
2. Izinkan "Instal aplikasi tak dikenal" untuk browser/pengelola file, lalu pasang.
   Bila sebelumnya memasang *TitikAntre*, hapus dulu aplikasi lama itu.
3. Masuk dengan username + PIN 6 digit, atau daftar lalu tunggu persetujuan koordinator.

APK untuk HP arm64 (hampir semua HP Android modern, Android 6+). Backend POC hanya aktif saat demo berlangsung.
